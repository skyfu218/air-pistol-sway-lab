# AimTrace｜空氣手槍穩定性分析

手機優先的教練輔助 Web App。以 MediaPipe Pose Landmarker 估算肩、肘、腕與軀幹姿態，並允許教練點選槍口／準星附近的 ROI，呈現即時晃動趨勢。

## 重要定位

- 所有相機畫面只在使用者裝置的瀏覽器內處理，不上傳、不儲存。
- 數值是「手機影像估算」，用於同人、同機、同角度下的趨勢比較。
- 小數位不代表儀器精度；本工具不宣稱 0.001° 關節角度準確度。
- 不替代測力板、光學動作捕捉、瞄準軌跡儀、醫療判斷或教練專業判讀。

## 功能

- 手機／平板／桌機響應式介面
- 即時側面相機畫面與 2D 骨架
- 左右持槍側選擇
- 持槍手相對晃動 RMS
- 肘角度、軀幹傾角與資料品質
- 畫面點選 ROI、局部樣板追蹤與位移欄位（MVP）
- 10／20／30 秒分析、摘要及 CSV 匯出
- 無相機時可使用「體驗示範」驗收流程

## 本機預覽

相機 API 需要安全來源；`localhost` 可直接使用。

```bash
python3 -m http.server 8080
```

開啟 `http://localhost:8080`。

## 技術與限制

- MediaPipe Tasks Vision 由 jsDelivr 載入，姿態模型由 Google Storage 載入；首次使用需要網路。
- 目前 ROI 採局部灰階樣板搜尋，微動追蹤仍屬 MVP；遇到遮擋、低紋理或大幅移動可能失鎖，必須用真實空氣手槍側面影片校正與驗證。
- 瀏覽器端姿態推論受手機效能、畫質、曝光、遮擋、鏡頭防震與網路首次載入速度影響。
- 正式研究使用前應與可追溯的參考系統比較信度、效度及最小可偵測變化。

## 安全

手機應固定於腳架，操作由安全位置的教練負責。射手持槍時不應分心操作裝置，並應遵循靶場及槍枝安全規範。
