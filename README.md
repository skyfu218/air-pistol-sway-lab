# AimTrace｜空氣手槍穩定性分析

手機優先的教練輔助 Web App。以 MediaPipe Pose Landmarker 估算肩、肘、腕與軀幹姿態，並允許教練點選槍口／準星附近的 ROI，呈現即時晃動趨勢。

## 重要定位

- 所有相機畫面只在使用者裝置的瀏覽器內處理，不上傳、不儲存。
- 數值是「手機影像估算」，用於同人、同機、同角度下的趨勢比較。
- 小數位不代表儀器精度；本工具不宣稱 0.001° 關節角度準確度。
- 不替代測力板、光學動作捕捉、瞄準軌跡儀、醫療判斷或教練專業判讀。

## 功能

- 手機／平板／桌機響應式介面
- 即時側面相機畫面與 2D 骨架
- 骨架顯示採分關節自適應平滑、低信心短暫保持及手臂肢段長度約束；ROI 軌跡仍獨立保留微動資訊
- 左右持槍側選擇
- 固定 3 秒準備倒數（不記錄）＋20 秒正式分析
- 點選 ROI 為主要持槍部位分析：上下／前後晃動量、最大範圍與軌跡長度
- 晃動軌跡只在按下「開始分析」後記錄；完成後保留該次分析軌跡
- 手槍 ROI 以真正的 X–Y 二維向量軌跡呈現，同時向左、向上時會落在左上象限
- 依輸入身高與頭到腳踝影像比例顯示每 0.1 cm 的估算尺規；至少呈現 ±1.0 cm
- 依時間順序保存所有有效 ROI 位置，使用固定線寬連接完整移動路徑，並標示起點與終點
- 「開始分析」位於側面拍攝影像下方，減少手機操作時的捲動
- 持槍手、肘角度、軀幹傾角與 2D 軀幹前後位移作為輔助判讀
- 畫面點選 ROI、局部樣板追蹤與位移欄位（MVP）
- 點選或重新選取 ROI 時，水平上下基準線立即移到該 ROI 中心位置
- 20 秒分析摘要及 CSV 匯出
- 真實影像上顯示即時穩定度及 2D 方向箭頭：手槍 ROI 上下、手槍 ROI 前後與軀幹前後
- 正式分析同步合成錄製影像、骨架、完整手槍 ROI 累積軌跡，以及穩定度、三方向位移、追蹤品質與時間碼；完成後可在同一裝置回放
- 回放影片可下載，並以手機原生分享選單傳送至 LINE；若瀏覽器不支援影片檔分享，會下載後提示手動附加
- 回放 HUD 沿用即時分析的四卡格式；方向變化時整張卡片亮綠，並直接疊加 ROI、2D 質心與持槍手肘完整軌跡
- 真實影像上依時間順序顯示手槍 ROI、肚臍附近 2D 質心與持槍手肘的完整移動軌跡及 ROI 水平基準線
- 完成分析後輸出包含拍攝畫面、ROI 軌跡與主／輔指標的 PNG 檢測報告
- 透過手機原生分享選單傳送至 LINE；不支援時自動下載報告供手動附加
- 公開顯示匿名累積的網站開啟、開始分析與完成分析次數
- 首次進入以匿名身分別與選填單位了解使用族群；私人提交不可由前台讀回
- 完成身分選擇後自動回到頁面最上方，依序瀏覽測驗流程並在頁尾看到建議區
- 頁尾提供私人匿名建議表單及使用者自行開啟 Email App 的寄送選項
- 臺灣運動健康科技學會 Logo、製作單位與 2026 年 10 月更新資訊
- 無相機時可使用「體驗示範」驗收流程
- Android 相機會由高到低逐步嘗試畫質與鏡頭條件，不強制最低幀率；GPU 姿態分析失敗時會自動改用 CPU
- 相機權限、裝置占用、無鏡頭與瀏覽器不支援會顯示各自的處理說明
- 相機模式建立 ROI 後即可啟動 3 秒倒數與 20 秒分析；骨架品質不足會警示，但不再鎖住開始按鈕
- Samsung／Android 會先以寬鬆的後鏡頭條件取得相機，再載入姿態模型；權限、App 占用或內建瀏覽器阻擋會直接在影像區顯示原因與重試按鈕

## 鏡頭方向

相機畫面與骨架均使用非鏡像顯示，左右方向和原始攝影畫面一致。

## 本機預覽

相機 API 需要安全來源；`localhost` 可直接使用。

```bash
python3 -m http.server 8080
```

開啟 `http://localhost:8080`。

## 技術與限制

- Samsung 相機權限若停在無回應狀態，會立即顯示等待提示，10 秒後轉為可操作的診斷訊息，不再讓按鈕無聲卡住。
- 外部影片匯入具備載入與跳轉逾時、格式錯誤說明、AI 掃描互斥及手機取樣上限；正式分析會在影片確實開始播放後才記錄。
- 外部影片會先完成起點定位再啟動分析狀態，避免背景迴圈把尚未開始的區間誤判為已結束；推論與合成回放採降載設定，報告會標示實際選取秒數。
- MediaPipe Tasks Vision 由 jsDelivr 載入，姿態模型由 Google Storage 載入；首次使用需要網路。
- 目前 ROI 採局部灰階樣板搜尋，微動追蹤仍屬 MVP；遇到遮擋、低紋理或大幅移動可能失鎖，必須用真實空氣手槍側面影片校正與驗證。
- 公分尺是依輸入身高與影像中頭到腳踝比例換算的估算值，受透視、站位、鏡頭畸變與關鍵點誤差影響，不是實體校正後的測量值。
- 軀幹前後位移是側面 2D 畫面中骨盆相對足部支撐基準的水平變化，不是 3D 深度或測力板位移。
- 手槍 ROI 與軀幹的「前後」是 2D 側面影像中的水平位移，不是真正的 3D 深度量測；真正 3D 姿態需要雙鏡頭、標記點或慣性感測器。
- 瀏覽器端姿態推論受手機效能、畫質、曝光、遮擋、鏡頭防震與網路首次載入速度影響。
- 回放影片優先採瀏覽器支援的 MP4／H.264，無法使用時改存 WebM；LINE 與部分 iPhone 對 WebM 的直接播放相容性可能有限。
- 穩定骨架用於降低視覺跳點與輔助解讀，不能把濾波後的小數位視為毫米級或醫療級量測精度。
- 正式研究使用前應與可追溯的參考系統比較信度、效度及最小可偵測變化。

## 安全

新增匯入既有影片、手動起訖時間軸與 AI 建議區間。影片僅在瀏覽器本機處理；點選槍口／準星 ROI 後，畫面會立即顯示十字、追蹤框與水平基準線。
AI 建議區間以舉槍完成後的穩定持槍平台為起點，以持槍手腕／手肘在穩定期間出現的瞬間運動尖峰作為擊發反應候選結束點。單機 2D 影像無法保證辨識每次擊發；未達可靠條件時會明確要求人工確認。

手機應固定於腳架，操作由安全位置的教練負責。射手持槍時不應分心操作裝置，並應遵循靶場及槍枝安全規範。
